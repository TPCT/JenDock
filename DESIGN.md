# Visual contract

Arabic operator workspace for inspecting GitHub deliveries and Docker runtime.
Use a persistent navigation rail, a compact status strip, project rows, chronological
deployment records and a searchable service table. Avoid decorative metric cards.
Warm neutral surfaces support long daytime reading; deep green is the primary
action, amber means pending, red means failure. State labels always accompany color.
Repository names, hashes and image references use LTR; Arabic content uses RTL.
Every displayed state comes from persisted deliveries or timestamped observations.
Stale observations remain visibly stale. No pretend live graphs or success states.

This is an implementation choice within the approved operations dashboard scope,
not a claim that the user approved a separate visual concept.
